# Valorous Rabbit

> 原作：**The frantic run of the valorous rabbit**，Karim Maaloul（Yakudoo）  
> 原始作品：[CodePen YGxYej](https://codepen.io/Yakudoo/pen/YGxYej)  
> 源码入口：[CodePen source view](https://codepen.io/Yakudoo/pen/YGxYej)  
> 许可：MIT（CodePen 公开 Pen 默认许可）

这是一个面向 AlterU 手机端的触屏改编版本。它保留原作的低多边形角色、球形跑道、相机、薄雾、光照、配色和追逐运动，并加入主动唤醒、Pointer Events、移动安全区、合成音效、平台用户名结算和生命周期暂停。

## 本地运行

```bash
npm install
npm run dev
```

使用 `?baseline=1` 进入机械对照模式。
