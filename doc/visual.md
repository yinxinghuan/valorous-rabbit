# 视觉文档

## 1. Visual thesis

- 游戏与受众：面向 AlterU 手机端用户的短时低多边形追逐视觉玩具。
- 情绪承诺：童话般柔和、角色动作可爱，但速度逐渐令人手忙脚乱。
- 一句话视觉命题：一支来自同一低多边形角色库的怪异逃亡队伍轮番冲过薄荷色球形原野，狼的鼻尖始终从画面左侧逼近。
- 标志性瞬间：兔子越过刺猬碰到胡萝卜，粉橙与绿色方块粒子从球面弧线上爆开。
- 三个必需品质：原作兔子与共享 GLB 都保留身份；每名角色动作剪影不同；UI 退后而主体始终明亮。
- 三个回避方向：霓虹赛博 HUD、写实毛发与照片纹理、通用玻璃卡片堆叠。

## 2. Composition and camera

- 方向与比例：产品入口以 9:19.5 竖屏为主，同时支持 320×568；基线保留宽屏原作构图。
- 相机与透视：50° 透视相机，侧向追逐视角，常态相机 z=160、y=30 并看向 y=30；结算轻推至 z=205，避免沿用桌面原作过远的 260。
- 画面焦点：当前角色位于视觉中心略偏右；狼从左后方逼近；球面地平线位于画面下方约 64%。
- 前中后景：前景为角色和碰撞物，中景为球面与松树，背景为纯色薄雾。
- HUD 安全区：距离位于 `max(16px, env(safe-area-inset-top)) + 12px`；静音按钮位于右上；底部操作区避开 `env(safe-area-inset-bottom)`。
- 注意路径：当前角色 → 即将到达的胡萝卜/刺猬 → 狼 → 顶部任务进度。

## 3. Color

- 背景 `#DBE6E6`；薄雾 `#D6EAE6`；草地 `#7ABF8E`；主文字 `#5B332A`；弱文字 `#6E827D`。
- 兔子/主体 `#B44B39`；脸颊与强调 `#DC5F45`；胡萝卜与动作 `#E07A57`；奖励绿 `#7ABF8E`；危险砖红 `#B44B39`；成功淡桃 `#FFC5A2`。
- 使用比例：背景与雾 65%，球面与树 20%，角色/道具 12%，UI 3%。
- 禁止组合：高饱和蓝紫渐变、纯黑大面积遮罩、同时使用两种发光描边。

## 4. Typography

- 距离数字：与《Get Off My Grave》一致使用本地打包的 `Creepster` 400，回退为 `Impact`；以不规则怪诞轮廓和 2 px 淡桃硬边错位呼应追逐中的狼与低多边形角色。
- 其他展示文字：`Arial Narrow`, `Roboto Condensed`, `"Noto Sans SC"`，700；结算用户名使用系统无衬线 700，避免怪诞字体污染中文可读性。
- UI/正文：`Inter`, `"Noto Sans SC"`, system-ui，500/600。
- HUD 距离数字 44–52 px、标签 11–12 px 全大写/中文短标签；结算距离数字 56–72 px，正文 14–16 px。
- 数字与英文标签使用 0.08em 字距；中文不强制大写；不使用文字描边。

## 5. Shape, material, and lighting

- 主导形状：上游的硬边方块几何与共享角色库的五种 flat-shaded 图元；UI 使用细线 SVG、切角标签与直角角色陈列格。
- 描边/边框/阴影：3D 无描边；按钮 1 px 深砖红边框，按下时内收 2 px；结算文字直接悬浮在场景上，不使用面板、模糊玻璃或投影遮挡最终追逐定格。
- 材质与纹理：保留 GLB 的 flat-shaded MeshStandardMaterial 与唯一 teal 强调色，不统一替换材质；无图片纹理。商店使用资产库透明 sprite；原作勇兔则从游戏内同一个程序化模型、材质和灯光直接渲染透明缩略图，禁止另画近似兔子。
- 光线与氛围：0.9 环境光，左上方白色方向光，薄雾遮蔽远景。

## 6. Characters, environments, and assets

- 比例与剪影：原作兔子保留长耳、方头、短尾；共享角色通过 inventory footprint、运行时 Box3 落地/居中，并限制到与兔子相同的屏幕尺寸带。所有动物显式校正模型前向轴，脸部或物种识别特征必须朝向观众，禁止尾部/背面成为第一读图。狼保持长鼻、张嘴与跟随弹性。
- 表情与姿态：每个角色拥有独立待机、奔跑、起跳、落地、撞击恢复和被捕定格；僵尸保留前伸手臂，狼人低身疾跑，机甲活塞重踏，幽灵漂浮，青蛙压缩弹跳，鸭子/鸡分别摇摆与拍翅。
- 透视、尺度与细节：所有资产使用同一低多边形密度与硬边光照；移动端不增加细碎装饰。
- 输出与裁切：无外部角色位图；正式海报为 1024×1024 PNG，另检 160×160 缩略图。

## 7. UI and icons

- 图标：自绘 24 px 线性 SVG，`viewBox="0 0 24 24"`、1.8 px 圆角笔画；用于角色、胡萝卜、静音、皇冠、箭头、锁和关闭，不使用 Emoji。
- 按钮层级：主按钮为淡桃底+砖红文字，最小 48 px 高；静音为 44×44 px 图标按钮。
- HUD 与面板：默认无尽 HUD 用顶部距离读数保持跑分焦点；主动切换的主线 HUD 再显示细进度轨、剩余时间与任务胡萝卜。左上为当前角色档案入口，真实角色缩略图、切换徽标与胡萝卜余额构成一个紧凑 dock。右上静音与排行榜皇冠垂直成组，均使用同一切角、细描边和硬阴影语言；皇冠从首局起可见，避免把榜单发现性绑在无尽结算。结算继续开放式悬浮。角色商店从底部进入，以暖纸档案册为基底、薄荷角色展台、两列切角卡与关卡编号标签组成“逃亡者登记册”；余额、关闭、始终可见的主线/无尽切换是独立工具组。模式按钮使用双线手绘路线、起点、终点旗与排行榜皇冠，正文明确写出目标模式及“距离排行榜 / 逐关解锁”的结果，不使用无含义折角装饰。
- 状态：按下内收；键盘焦点用 2 px 深砖红外环；禁用降至 45%；排行榜加载显示三点节拍，空榜和失败使用短文案，站外使用 AlterU CTA；成功用粒子和文字共同表达。
- Emoji policy：禁止用 Emoji 充当功能图标。

## 8. Motion and VFX

- 动作个性与时长：奔跑为循环正弦摆动；起跳 0.8 秒；UI 状态 180–260 ms，`cubic-bezier(.2,.8,.2,1)`。
- 命中/奖励：收集粒子峰值在触发后 80 ms，0.5 秒内散开并收束；撞击背景闪烁 0.5 秒。
- 粒子：立方体，粉橙与草绿各 10 个，寿命 0.5 秒。
- 角色动作：根位移与四肢相位每帧从各自 rest pose 叠加；跳跃具备 80–140 ms 的角色化蓄力，接触峰值 60–100 ms，180–260 ms 恢复。减少动态模式保留姿势差异但缩小根弹跳与倾斜 55%。
- 屏幕震动/停帧：撞击最多 4 px、120 ms；不使用冻结帧。
- 减少动态：关闭相机震动、背景闪烁与多粒子，保留必要位移。

## 9. References translated into principles

- Reference：Karim Maaloul / Yakudoo，《The frantic run of the valorous rabbit》，CodePen YGxYej。
- 有用原则：用旋转球面和角色循环替代平移世界，少量方块几何即可形成完整追逐叙事。
- 适配：保留几何、相机、颜色、雾、灯光与跑动公式；只压缩 HUD、加入场景内幽灵手引导、触控反馈和安全区。
- 不复制内容：不继续分发来源不明的 Vivaldi MP3 录音，改用本地 Web Audio 合成反馈；不沿用桌面底部 credits 布局；不增加独立启动封面。

## 10. Anti-patterns

- 禁止 Emoji、写实动物模型或另一套图标风格；禁止把库内角色重新用临时方块拼一遍；排行榜头像仅作为真实玩家身份标识出现。
- 禁止彩虹渐变、Bloom、玻璃模糊、深色遮罩盖住最终追逐画面。
- 禁止把画布装进居中的圆角卡片；禁止三条命；主线时间是逃脱节奏而不是屏幕中央倒计时，排行榜只记录无尽跑酷距离。
- 禁止所有角色使用同一绝对关节角、同一跑步振幅或通用 fallback；角色缺动作 profile 必须在构建/验证阶段报错。
- 视觉漂移示例：兔子缩到 HUD 大小、球面变平地、用通用粒子雨替代方块碰撞爆发。

## 11. Vertical-slice acceptance

- 入口：打开即异步初始化 WebGL 并进入默认无尽追逐场景；首触前暂停玩法，只显示循环轻触的幽灵手引导，不使用启动封面或开始按钮。
- 游戏：原作勇兔与共享库 52 名角色、狼、球面、树、胡萝卜与刺猬在 390×844 中均清晰；最高、最宽、最长和最小角色在 320×568 中也不裁切。
- 全量角色：运行轮播必须得到 52 个唯一 `category/id`，动物脸部朝向正确，浅色、深色、透明与金属材质在真实灯光下都可读。
- 长商店：53 张角色卡在 320×568 中可纵向滚到底，购买后保留滚动位置，不横向溢出。
- 高反馈：收集与碰撞在同一帧得到视觉回应，且音效不阻塞。
- 商店：锁定、可购买、已拥有、已装备、余额不足、购买成功和加载失败均有稳定布局；原作兔子卡和左上入口均使用同一个真实程序化模型缩略图；320×568 可滚动且没有 pointerdown 抢滚动。
- 排行榜：主线与无尽均可从右上皇冠打开；榜单打开时追逐暂停。390×844 与 320×568 中标题、前三行、本人标记、头像与关闭按钮均可见且无横向溢出。
- 结束：被捕和逃脱两种定格仍可观看；主线显示解锁与下一位，无尽显示距离榜。
- 窄屏：320×568 无横向溢出，44 px 目标与底部安全区完整。
- 视觉 QA：390×844 与 320×568 已完成首轮和复验；前景树遮挡与 Guest Shell 覆盖两个 P1 已修复，结算图标/署名两个 P2 已修复；最终平均分 4.29，无 P0/P1 遗留。
