# 需求文档

## 1. Overview

《勇兔奔野》是一款面向 AlterU 手机端的竖屏低多边形无尽跑酷：玩家默认进入不设距离上限的全球排行追逐，在不断旋转的球形原野上收集胡萝卜、避开刺猬并逃离追逐狼；另可主动切换到 53 个主线试跑关，轮流解锁原作勇兔与共享库全部 52 名正式角色。

### 界面简报

- 玩家与场景：AlterU 用户，默认无尽单局约 30–180 秒，主动选择的主线关卡约 90–150 秒，单手竖屏使用。
- 情绪承诺：先被柔和童话般的低多边形原野吸引，再感到速度逐渐失控的轻微慌张与欢乐。
- 核心动作：在画布任意安全区域轻触一次，立即起跳。
- 主要状态：首帧加载、幽灵手引导、奔跑、跳跃、收集、受阻、关卡完成、追上失败、角色解锁、角色商店、购买成功/余额不足、无尽模式、排行榜、重试、GLB/WebGL 加载失败。
- 目标设备：390×844 与 320×568；Pointer、Touch 与键盘 Space/ArrowUp；适配顶部与底部安全区。
- 上游约束：必须保留原作的球面跑道、狼/刺猬/胡萝卜/松树、薄雾、低饱和薄荷背景、侧向追逐构图、逐渐加速和弹性角色动画；原作兔子仍是免费初始角色和动作质量基准。
- 完整主线共 53 名角色：原作勇兔加共享角色库当前全部 52 名正式角色。孩子、老人、职业人物、僵尸、狼人、幽灵、骷髅、木乃伊、机甲、神话角色与 11 种动物均必须拥有符合身份的动作性格；禁止静默回退到统一人形步态。共享库日后新增角色时，只有完成动作与移动端视觉验收后才能进入商品列表。
- 明确不做：不改成倒计时关卡、不加入三条命、不把上游主体缩成 UI 卡片里的背景。

## 2. Visual Design

主体占据中下部约 70% 的无边框 WebGL 画布；关卡进度、角色头像、胡萝卜钱包与静音控制位于顶部安全区，避开主要跳跃路径。角色商店是用户主动打开的响应式覆盖层，使用共享资产库透明 sprite 作为预览；关闭后返回同一暂停场景，不增加启动页。页面打开后异步初始化当前角色 GLB，首个可交互帧出现后以幽灵手引导第一次轻触。结算保持开放式悬浮排版，不用实体成绩牌遮挡狼追上角色的定格；`?baseline=1` 保留原作兔子机械对照入口。

## 3. Game Mechanics

- 初始速度为 5 世界单位/秒，每 3 秒提高 2，最高速度为 48。
- 球面跑道半径为 200；每帧旋转增量为 `delta × 0.03 × speed`。
- 距离每帧增加 `delta × speed`，显示值为向下取整后的 `distance / 2`。
- 兔子初始纵向位置为 0；起跳分上升与下降两段，总时长 0.8 秒，峰值高度 45；跳跃中再次轻触不叠加第二次跳跃。
- 胡萝卜碰撞半径为 20；收集后生成 20 个方块粒子，持续 0.5 秒，并把狼的目标位置向后推 0.025。
- 刺猬碰撞半径为 10；碰撞后刺猬飞出 4 秒，背景以最高 0.5 的砖红透明度闪烁 0.5 秒，并把狼的目标位置向前拉 0.04。
- 狼的位置以每帧 0.004 的最大步长追随目标值；位置达到 0.56 时触发追上结算。
- 第 `n` 关目标时长为 `min(150, 90 + (n - 1) × 2)` 秒；任务胡萝卜为 `min(10, 3 + floor((n - 1) / 6))` 根。时间达标但收集不足时继续奔跑；两项都达标后立即完成关卡。
- 主线模式狼的基础逼近速度降为每秒 0.0011；每撞到一次刺猬额外前拉 0.04，每收集一根胡萝卜后推 0.025。球面速度沿用原作每 3 秒提升 2、上限 48 的节奏，使长关卡后段仍持续加压。
- 主线固定使用当关试用角色；通关后角色立即加入已解锁 roster，并可在无尽模式装备。最终关完成后允许用最终角色重跑。
- 胡萝卜在拾取当帧同时计入本关任务与永久钱包，即使本轮失败也保留。所有未解锁主线角色都可按 60、120、220、360、560 根五档价格提前购买；余额不足不扣款。
- 角色至少定义 `idle/run/jump/land/hit/caught` 六种状态。动作使用角色 GLB 的 rest pose 叠加四肢、根位移、倾斜、压缩和恢复；幽灵与无便携四肢 rig 的动物使用显式 root motion profile，不回退到人形动作。
- 无尽模式从首局起开放且是默认入口，没有距离上限、里程碑终点或破纪录自动结算；只有狼实际追上玩家才结束本轮并提交全球距离榜。53 关主线作为角色商店内可随时主动选择的独立模式，成绩不提交距离榜。
- 结算后画面继续渲染最终追逐构图，速度在 1 秒内降为 0，0.8 秒后开放重试。
- AlterU 内每轮无尽追逐结算把整数距离提交到当前游戏 UUID 的平台排行榜；开始新一轮前记录自己的旧最佳成绩，仅当本轮刷新个人最佳时，查找被刚刚超过且分数最高的一名玩家并发送一次 `score_beat` 通知。
- AlterU 内从主线第 1 关起即可随时打开排行榜查看当前冠军与完整榜单；查看权限不依赖当前模式，但只有无尽模式提交距离。完整榜单显示名次、头像、用户名、距离与自己的标记，其他玩家行可打开其 AlterU 资料。平台外不请求榜单，只显示 AlterU 下载入口。
- 页面隐藏或画布大部分离开视口时暂停 RAF、动画和音频；重新可见时继续。
- `prefers-reduced-motion` 下保留运行与跳跃判定，但关闭背景闪烁、相机推拉和高密度粒子。

## 4. Controls

- 首次引导：页面打开即加载场景；首个可交互 3D 帧出现后暂停世界，循环显示轻触手势，首次真实轻触恢复世界并立即起跳。
- 奔跑中：画布 `pointerdown`、Space 或 ArrowUp 触发一次跳跃。
- 结算中：轻触“再跑一次”按钮或按 Enter 重置距离、速度、角色位置和障碍状态。
- 排行榜：轻触游戏右上方 48×48 px 皇冠入口，或无尽结算中的冠军条，打开完整榜单；打开榜单时暂停追逐，榜单可纵向滚动，轻触其他玩家行打开其资料，轻触 44×44 px 关闭按钮返回并恢复游戏。
- 静音：右上角 44×44 px SVG 按钮切换合成音效；状态同时通过图标和可访问标签表达。
- 商店：左上角 44×44 px SVG 角色按钮打开商店并暂停玩法；商店列表使用 `click` 选择、购买或装备，允许纵向滚动。关闭后恢复打开前的暂停/运行状态。
- 模式切换：角色商店从第 1 局起显示 48 px 高的模式按钮；无尽中轻触进入主线，主线中轻触返回默认无尽。切换通过页面重载建立干净的新对局，不沿用另一模式的距离或任务进度。
- 关卡切换：通关后轻触“下一位”进入下一角色试跑；失败后“再试一次”保持当前角色和任务进度规则不变。
- 不依赖 hover；交互元素关闭触控高亮并禁止文本选中。

## 5. Win / Lose Conditions

主线关卡在达到目标时长并收集足够任务胡萝卜后胜利；通关直接解锁当关角色，并显示下一角色、钱包增量和“下一位”动作。每轮重置时狼从 0.65 的安全距离开始追逐，位置低于 0.56 时失败，显示本关时间/收集进度和快速重试。无尽模式没有固定胜利终点，狼追上时显示距离、胡萝卜数、全球名次、冠军入口和重试。排行榜或存档失败不阻塞本地解锁、购买和继续游戏。

## 6. Sound Effects

- 起跳：220→360 Hz 正弦波上滑，90 ms，快速起音、60 ms 衰减，音量 0.06。
- 收集：520、660、820 Hz 三个三角波依次进入，总长 180 ms，音量 0.07。
- 撞击：90→45 Hz 锯齿波下滑并叠加 80 ms 低通噪声，总长 220 ms，音量 0.08。
- 追上结算：196、164、130 Hz 三个正弦波下行，总长 600 ms，音量 0.06。
- 关卡完成：392、523、659、784 Hz 三角波依次进入，总长 720 ms，音量 0.07。
- 角色解锁/购买：440→880 Hz 上滑叠加 660 Hz 短音，总长 360 ms，音量 0.055。
- 余额不足：140→110 Hz 方波双脉冲，总长 180 ms，音量 0.035。
- 音频仅在首次用户手势后创建或恢复 AudioContext；失败不阻塞游戏；同时发声上限为 4。
