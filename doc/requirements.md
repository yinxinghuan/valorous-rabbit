# 需求文档

## 1. Overview

《勇兔奔野》是一款面向 AlterU 手机端的竖屏低多边形跑酷视觉玩具：玩家轻触屏幕让兔子跃起，在不断旋转的球形原野上收集胡萝卜、避开刺猬，并尽可能延长与追逐狼之间的距离。

### 界面简报

- 玩家与场景：AlterU 用户，单次体验约 30–120 秒，单手竖屏使用。
- 情绪承诺：先被柔和童话般的低多边形原野吸引，再感到速度逐渐失控的轻微慌张与欢乐。
- 核心动作：在画布任意安全区域轻触一次，立即起跳。
- 主要状态：首帧加载、幽灵手引导、奔跑、跳跃、收集、受阻、追上结算、重试、WebGL 不支持/加载失败。
- 目标设备：390×844 与 320×568；Pointer、Touch 与键盘 Space/ArrowUp；适配顶部与底部安全区。
- 上游约束：必须保留原作的球面跑道、方块化兔子/狼/刺猬/胡萝卜/松树、薄雾、低饱和薄荷背景、正交侧向追逐构图、逐渐加速和弹性角色动画。
- 明确不做：不改成倒计时关卡、不加入三条命、不把上游主体缩成 UI 卡片里的背景。

## 2. Visual Design

主体占据中下部约 70% 的无边框 WebGL 画布；跑动距离位于顶部安全区，提示与静音控制避开主要跳跃路径。画面沿用原作的薄荷灰天空、绿色球面、砖红兔子、粉橙胡萝卜与追逐狼，界面使用细线 SVG 图标和窄体无衬线文字。页面打开后立即异步初始化 3D 场景，首个可交互帧出现后以幽灵手引导第一次轻触；结算保持开放式悬浮排版，不用实体成绩牌遮挡狼追上兔子的定格，只提供本轮距离、胡萝卜数、全球名次、冠军入口与重试；`?baseline=1` 保留机械对照入口。

## 3. Game Mechanics

- 初始速度为 5 世界单位/秒，每 3 秒提高 2，最高速度为 48。
- 球面跑道半径为 200；每帧旋转增量为 `delta × 0.03 × speed`。
- 距离每帧增加 `delta × speed`，显示值为向下取整后的 `distance / 2`。
- 兔子初始纵向位置为 0；起跳分上升与下降两段，总时长 0.8 秒，峰值高度 45；跳跃中再次轻触不叠加第二次跳跃。
- 胡萝卜碰撞半径为 20；收集后生成 20 个方块粒子，持续 0.5 秒，并把狼的目标位置向后推 0.025。
- 刺猬碰撞半径为 10；碰撞后刺猬飞出 4 秒，背景以最高 0.5 的砖红透明度闪烁 0.5 秒，并把狼的目标位置向前拉 0.04。
- 狼的位置以每帧 0.004 的最大步长追随目标值；位置达到 0.56 时触发追上结算。
- 结算后画面继续渲染最终追逐构图，速度在 1 秒内降为 0，0.8 秒后开放重试。
- AlterU 内每轮结算把整数距离提交到当前游戏 UUID 的平台排行榜；开始新一轮前记录自己的旧最佳成绩，仅当本轮刷新个人最佳时，查找被刚刚超过且分数最高的一名玩家并发送一次 `score_beat` 通知。
- 排行榜入口显示当前冠军的头像、用户名和距离；完整榜单显示名次、头像、用户名、距离与自己的标记，其他玩家行可打开其 AlterU 资料。平台外不请求榜单，只显示 AlterU 下载入口。
- 页面隐藏或画布大部分离开视口时暂停 RAF、动画和音频；重新可见时继续。
- `prefers-reduced-motion` 下保留运行与跳跃判定，但关闭背景闪烁、相机推拉和高密度粒子。

## 4. Controls

- 首次引导：页面打开即加载场景；首个可交互 3D 帧出现后暂停世界，循环显示轻触手势，首次真实轻触恢复世界并立即起跳。
- 奔跑中：画布 `pointerdown`、Space 或 ArrowUp 触发一次跳跃。
- 结算中：轻触“再跑一次”按钮或按 Enter 重置距离、速度、角色位置和障碍状态。
- 排行榜：轻触结算成绩牌中的冠军条打开完整榜单；榜单可纵向滚动，轻触其他玩家行打开其资料，轻触 44×44 px 关闭按钮返回结算。
- 静音：右上角 44×44 px SVG 按钮切换合成音效；状态同时通过图标和可访问标签表达。
- 不依赖 hover；交互元素关闭触控高亮并禁止文本选中。

## 5. Win / Lose Conditions

这是无固定胜利终点的生存跑酷视觉玩具。胡萝卜让玩家暂时拉开追逐距离，刺猬让狼逼近；当狼的位置达到 0.56 时本轮结束。结算层显示当前 AlterU 用户名、最终距离、收集胡萝卜数量、全球名次、冠军榜单入口、一次明确的重试动作和原作署名入口。排行榜失败不阻塞结算和重试。

## 6. Sound Effects

- 起跳：220→360 Hz 正弦波上滑，90 ms，快速起音、60 ms 衰减，音量 0.06。
- 收集：520、660、820 Hz 三个三角波依次进入，总长 180 ms，音量 0.07。
- 撞击：90→45 Hz 锯齿波下滑并叠加 80 ms 低通噪声，总长 220 ms，音量 0.08。
- 追上结算：196、164、130 Hz 三个正弦波下行，总长 600 ms，音量 0.06。
- 音频仅在首次用户手势后创建或恢复 AudioContext；失败不阻塞游戏；同时发声上限为 4。
